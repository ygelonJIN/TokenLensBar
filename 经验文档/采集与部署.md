# 采集与部署

**什么时候读**：采集漏数、换机器、launchd 不跑、构建失败、多机接远程源、想重装或删数据。

## 采集靠什么触发

**什么时候用**：怀疑「定时没跑」或者数据延迟。

不是纯定时：**文件变化触发**，launchd 每 5 分钟兜底扫一次，电脑唤醒时立即补一次。
App 关掉不影响采集，菜单栏只是读 SQLite 的展示层。

**坑**：别为了「更实时」把间隔调到 1 分钟。原因已经不是 CPU——单轮采集现在只要
0.1 秒（见 `性能与开销.md`），调快也不会卡——而是每轮都要起一个 Python 进程、
写一行日志，收益换不来这些开销。

## zstd 找不到

**什么时候用**：launchd 定时采集什么都没采到，手动跑却正常。

launchd 给的 `PATH` 只有 `/usr/bin:/bin:/usr/sbin:/sbin`，Homebrew 的 zstd 不在里面。
`tokenlensbar.py` 里用 `ZSTD_SEARCH_PATHS` 显式找 `/opt/homebrew/bin/zstd` 等几个位置，
`TOKENLENSBAR_ZSTD` 可以覆盖。

**坑**：会话文件正在写入时会被跳过，等下一次扫描，不是丢数据。

## 构建缓存不能放外置盘

**什么时候用**：`./build.sh` 报 SIGTRAP 或 module cache 相关错误。

仓库在外置 exFAT 卷上，`swiftc` 的 module cache 放这里会崩。
`build.sh` 已固定到 `/tmp/tokenlensbar-modcache`；移动仓库后重跑 `./build.sh` 即可。

## 去重靠稳定 ID

**什么时候用**：发现同一条请求被算了两遍，或改了归一化口径要迁移历史。

主键是 `session:turn:step`（Codex 用 `response_id`），写入用 upsert：
新行插入，已存在的行只在 `ts` 变化时更新 `ts`，其它字段不动。
重复扫描、补扫、崩溃恢复都幂等。

**坑**：Hermes 的 `session_model_usage` 是**累计快照**，每次必须整表覆盖，
当增量追加会重复计数；Codex / DSH 才是增量。覆盖现在是逐行
`on conflict do update`（只写变化的行）+ 清理快照里消失的行，不再整表删。

**坑**：累计快照源的 ID 必须**拼满源表的主键列**。Hermes 的主键是六列
（会话、模型、服务商、**服务地址**、**计费方式**、任务），早先只用了四列，
而服务地址实际出现过 `https://api.xiaomimimo.com/v1` 和 `/v1/` 两种写法——
同会话两行就会撞同一个 ID，数据库按 ID 覆盖，静默少一行且不报错。
现在 `snapshot_id()` 用六列取 sha1 前 20 位（字段里可能有冒号，所以用 `\x1f` 分隔）。

**一次性迁移**：`python3 tokenlensbar.py migrate-ids`（先 `--dry-run` 看清楚）。
旧 ID 用冒号拼接、字段本身可能含冒号，没法反解析，所以迁移是
「删掉该源的行 → 按源库当前内容重扫」。**源库已经清理掉的历史会话会随之消失**，
跑之前先 `cp usage.db usage.db.bak`。迁移完核对 `events` 总数、各 agent token、
金额、daily 数组四项全等，且 `select id from events group by id having count(*)>1` 为空。

**口径迁移**：改了计费时刻的取法（例如从消息时刻改成 `step/start`），
靠重扫一遍旧文件把 `ts` 改正，不需要删库；但前提是旧会话文件还在 `~/.dsh/sessions` 里。

## 多机：远程源

**什么时候用**：树莓派或另一台机器上的 agent 用量要汇总到本机。

1. 本机到远端配免密 SSH（只需一次）。
2. 登记远程源（`tokenlensbar.py` 的子命令，见 `--help`）。
3. 验证：跑一次 report，确认远端那几天的数据进来了。

**坑**：远端时间戳只有「会话最后活动」，分不清峰谷，这类来源在 `peak_only_agents` 里按高峰价算。

## 回退

**什么时候用**：升级出问题、配置改坏、想从头来。

- 重装：`./build.sh && ./install.sh`，不会动 `~/.tokenlensbar/`。
- 改坏配置：`prices.json` / `balances.json` 都有 `.example.json` 模板，复制回去即可。
- **删数据是不可逆的**：`~/.tokenlensbar/usage.db` 存全部历史 token、余额样本和手动补记。
  真要重来，先 `cp usage.db usage.db.bak`；删除后只能重新采集，之前的余额样本找不回来。
- `launchd` 那几项：`launchctl list | grep tokenlens` 看是否加载，卸载用 `install.sh` 里对应的 `uninstall` 逻辑。
